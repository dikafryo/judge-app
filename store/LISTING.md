Play Console → 스토어 설정 · 기본 스토어 등록정보에 그대로 붙여 넣는다.
괄호 안은 플레이가 정한 글자 수 상한이다.

## 앱 이름 (30자)

```
온라인 심사 시스템
```

## 간단한 설명 (80자)

목록과 검색 결과에 뜨는 한 줄. 여기서 "무엇을 하는 물건인지" 끝나야 한다.

```
종이 심사표 없이 진행하는 심사 도구. 채점부터 집계, 결재용 최종집계표까지.
```

## 자세한 설명 (4000자)

```
경진대회·공모전·심사위원회를 종이 없이 진행하는 도구입니다.
심사위원은 받은 코드로 바로 들어와 채점하고, 주최자는 집계가 끝난 표를 그대로 인쇄해 결재에 올립니다.

■ 회원가입이 없습니다

심사위원은 6자리 코드나 QR 한 번으로 들어옵니다. 계정을 만들 필요도, 비밀번호를 기억할 필요도 없습니다.
행사 당일 처음 앱을 켠 심사위원이 설명 없이 바로 채점을 시작할 수 있도록 만들었습니다.

■ 네트워크가 끊겨도 채점은 멈추지 않습니다

체육관·강당·지하 회의실에서 신호가 잡히지 않는 일은 흔합니다.
이 앱은 연결이 끊긴 채로도 채점 화면이 그대로 동작하고, 입력한 점수는 기기에 쌓입니다.
신호가 돌아오면 쌓인 점수를 알아서 보냅니다. 같은 점수가 두 번 저장되지 않도록 처리되어 있습니다.

■ 블라인드 심사

기본값은 평가 대상의 이름을 감추고 심사번호만 보여 주는 방식입니다.
이름을 공개하는 방식으로 바꿀 수도 있으며, 최종집계표에는 항상 이름이 함께 나옵니다.

■ 집계는 기다리지 않아도 됩니다

누가 어디까지 채점했는지, 현재 순위가 어떻게 되는지 관리 화면에서 바로 보입니다.
집계 방식은 두 가지 중에 고릅니다.

· 전체 합계·평균
· 최고·최저 총점을 준 심사위원을 빼고 계산 (채점 3인 이상일 때 적용)

선정 인원 수를 정해 두면 상위 몇 곳이 선정인지 표시하고, 커트라인에서 동점이 생기면 경고합니다.
동점을 모르고 발표하는 사고를 막기 위한 것입니다.

■ 결재에 그대로 쓰는 최종집계표

A4 한 장으로 떨어지는 최종집계표를 출력합니다.
심사위원 전원의 서명란과 기록자·검토자·확인자 결재란이 들어가고, 제외된 점수는 취소선으로 남아
표에 적힌 숫자만으로 총점을 되짚을 수 있습니다.
심사위원별 개별심사표, 엑셀에서 바로 열리는 CSV 도 함께 뽑을 수 있습니다.

■ 전자서명

심사위원이 화면에 손가락으로 서명하면 출력물의 서명란에 그대로 들어갑니다.
인쇄한 뒤 자필로 다시 받아도 됩니다.

■ 이런 곳에 씁니다

· 학생 경진대회, 발표회, 공모전 심사
· 기관 선정 심사, 제안서 평가
· 동아리·행사 내부 평가

■ 알아 두실 점

· 심사 데이터는 운영자가 관리하는 서버에 저장됩니다.
· 카메라는 QR 코드로 입장할 때만 쓰며, 영상은 저장하거나 보내지 않습니다. 코드를 손으로 입력해도 됩니다.
· 광고가 없고, 이용 행태를 추적하는 분석 도구를 넣지 않았습니다.
· 아이폰과 데스크톱에서는 웹(judge.sw4u.kr)으로 같은 기능을 씁니다.

문의: judge.sw4u.kr
```

### 스크린샷으로 담을 화면 (권장 순서)

플레이는 스크린샷이 실제 앱 화면일 것을 요구한다. 아래 순서가 "무엇을 하는 앱인지"를 가장 빨리 전달한다.

1. 심사위원 입장 화면 — 코드 입력 / QR
2. 채점 화면 — 항목별 점수 입력
3. 오프라인 표시가 뜬 채점 화면 — 이 앱의 핵심 차별점
4. 관리자 집계 대시보드 — 순위와 진행률
5. 최종집계표 인쇄 미리보기

체험용 샘플 행사(`php artisan judge:demo`)로 찍으면 실제 사람 이름이 들어가지 않는다.

### 데이터 안전 (Data safety) 신고 내용

수집해서 **서버로 전송**하는 것:

| 데이터 | 목적 | 비고 |
|---|---|---|
| 이름 (심사위원·평가 대상) | 앱 기능 | 주최자가 입력 |
| 사용자 생성 콘텐츠 (점수, 전자서명 이미지) | 앱 기능 | 심사위원이 입력 |

· 전송 구간은 HTTPS 로 암호화된다 → "전송 중 암호화됨" 예
· 삭제를 요청할 수 있다 → 예 (행사를 삭제하면 관련 정보가 즉시 전부 삭제된다)
· 제3자 공유 없음, 광고·분석 목적 수집 없음
· **카메라 영상은 수집 항목이 아니다** — QR 을 읽는 즉시 버리고 저장·전송하지 않는다
· 기기 안 오프라인 대기열은 전송이 아니므로 수집에 해당하지 않는다
